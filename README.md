# راند — دستیار اینترنی اطفال

یک PWA تک‌فایل و صدا-محور برای راند اطفال. فرم پر نمی‌کنی — حرف می‌زنی:

> «تخت ۱۲ سی‌بی‌سی و سی‌آرپی بفرست» · «تخت ۱۲ جوابش آمد، WBC چهارده» · «تخت ۷ ال‌پی شد»

اپ جمله را می‌فهمد، به تخت درست وصل می‌کند و کار/جواب/یادداشت را سر جایش می‌گذارد.
بعد در **جدول راند** همه‌ی تخت‌ها و کارهای مانده‌شان را یک‌جا می‌بینی.

بدون کلید API هم با یک پارسر ساده‌ی آفلاین کار می‌کند.

- **ماشین‌حساب دوز** mg/kg و **محدوده‌ی نرمال علائم حیاتی (PALS)** بر حسب سن
- **دیکته‌ی صوتی** فارسی
- **تشخیص افتراقی** و **تولید پاورپوینت** با کمک هوش مصنوعی

## حریم بیمار

همه‌ی داده‌ها فقط در حافظه‌ی همان دستگاه (`localStorage`) می‌ماند؛ هیچ سروری در کار نیست.
تنها وقتی چیزی به بیرون می‌رود که کاربر خودش دکمه‌ی AI را بزند — و آن هم یک خلاصه‌ی
**بی‌نام** است (بدون نام، شماره تخت، تاریخ یا هر شناسه‌ای) که پیش از ارسال به کاربر
نشان داده می‌شود تا تأیید یا ویرایشش کند.

کلید API فقط روی دستگاه کاربر ذخیره می‌شود و در مخزن نیست.

## نصب روی آیفون

در Safari آدرس را باز کن → دکمه‌ی Share → **Add to Home Screen**.
